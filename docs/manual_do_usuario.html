Manual do Usuário do Tomus

Para: Pesquisadores, Professores, Estudantes e Bibliotecários • Sistema: macOS 14+ • Linguagem: Acessível e Direta

1. O que é o Tomus e como ele ajuda sua pesquisa?

Seja bem-vindo ao Tomus! Ele foi concebido para eliminar o caos de pastas lotadas de PDFs com nomes estranhos (como artigo_versao2.pdf ou download.pdf). Com poucos cliques, o Tomus examina seus arquivos, descobre os dados da obra (título, autor, ano) e organiza tudo em pastas temáticas segundo a classificação oficial da CAPES/CNPq, gerando ainda a citação completa na norma ABNT NBR 6023.

Segurança em primeiro lugar: Seus arquivos PDF nunca saem do seu Mac. Toda a manipulação de arquivos e a leitura de documentos é realizada localmente no seu computador.

2. Instalação Passo a Passo no macOS

  1. Baixe o arquivo de instalação Tomus-1.2.0.dmg na página oficial do projeto.
  2. Dê um duplo clique no arquivo .dmg baixado para abrir a janela de instalação.
  3. Arraste o ícone do Tomus para a pasta Aplicativos.
  4. Abra o Tomus pelo Launchpad ou pelo Finder.
Aviso do macOS na 1ª abertura: Se o sistema alertar que o aplicativo é de desenvolvedor não verificado, clique em OK, abra os Ajustes do Sistema › Privacidade e Segurança, role até o final da tela e clique em Abrir Mesmo Assim. Você só precisará fazer isso uma vez!

3. Como Obter suas Chaves de Inteligência Artificial (API Keys)

Uma chave de API é como uma senha de acesso que permite ao Tomus se conectar aos cérebros de inteligência artificial diretamente, sem nenhum intermediário. A maioria dos provedores oferece planos gratuitos muito generosos para você usar sem gastar nada.

1

Google Gemini (Recomendado — Gratuito e Muito Rápido)

O Gemini é o motor primário do Tomus. Ele tem facilidade com textos longos e entende perfeitamente o português.

  1. Acesse o portal: aistudio.google.com e faça login com sua conta Google (Gmail).
  2. No menu lateral esquerdo, clique no botão azul Get API Key (Obter Chave).
  3. Clique em Create API Key e escolha Create API Key in new project.
  4. Copie a chave que se inicia com AIzaSy....
2

Groq (Excelente Reserva Gratuita — 1.000 requisições/dia)

O Groq é ultra-veloz e oferece gratuitamente 1.000 consultas por dia. É o parceiro perfeito para atuar como reserva automática se o Gemini atingir o limite diário.

  1. Acesse o console: console.groq.com e crie sua conta gratuita.
  2. No menu lateral esquerdo, clique em API Keys.
  3. Clique em Create API Key, dê o nome de Tomus e confirme.
  4. Copie a chave gerada (iniciada em gsk_...). Guarde-a logo, pois ela só aparece uma vez!
3

Anthropic Claude (Altíssima Precisão para Obras Raras)

O Claude se destaca por sua exatidão ao identificar livros antigos, teses e periódicos científicos complexos.

  1. Acesse o portal: console.anthropic.com e faça login.
  2. Vá até a aba API Keys e clique em Create Key.
  3. Na tela de criação:
    • Nome: Digite Tomus.
    • Expira: Selecione Nunca.
    • Escopo: Selecione Espaço de trabalho padrão (Default workspace).
  4. Clique em Criar chave e copie o código (começa com sk-ant-...).
4

NVIDIA NIM & DeepSeek

Você também pode utilizar o NVIDIA NIM (build.nvidia.com) com o modelo Llama 3.2 90B ou o DeepSeek (platform.deepseek.com).

5

Google Books API (Identificação Rápida de Livros por ISBN)

O Tomus procura códigos de barras de livros (ISBN) nas primeiras páginas. Com uma chave gratuita do Google Books, ele baixa a capa, a editora e o ano exato do livro.

  1. Acesse o console.cloud.google.com.
  2. Crie um projeto simples (ex: Tomus Livros).
  3. Pesquise por Books API no topo da página e clique em Ativar.
  4. Na aba Credenciais, clique em Criar Credenciais › Chave de API e copie sua chave.

Onde Colocar as Chaves no Tomus?

No Tomus, abra o menu superior Tomus › Preferências (ou pressione Cmd + ,). Cole suas chaves nos campos correspondentes e clique em Salvar. O Tomus testa automaticamente a conexão para você não ter surpresas durante a organização.

4. Operando a Bancada do Tomus

  1. Escolha a Pasta de Origem: Clique no botão de pasta ao lado de "Origem" e aponte para onde estão os seus PDFs soltos.
  2. Escolha a Pasta de Destino: Clique no botão ao lado de "Destino" e escolha onde sua nova biblioteca catalogada deve nascer.
  3. Escolha o Modo de Operação:
    • Copiar (Recomendado): Mantém seus arquivos originais intocados e cria uma cópia perfeitamente catalogada e renomeada no destino.
    • Mover: Transfere os arquivos para a nova estrutura de pastas (útil para quem tem pouco espaço em disco).
  4. Clique em "Organizar Acervo": Pronto! O Tomus iniciará a esteira de processamento. Você verá a barra de progresso avançar e os documentos catalogados aparecendo em tempo real na tela.

5. Explorando sua Biblioteca Organizada

  • Árvore Temática CAPES: Na barra lateral, navegue pelas Grandes Áreas (ex: Ciências Humanas), Áreas Básicas (ex: Educação) e Subáreas para ver quantos e quais livros você possui sobre cada assunto.
  • Busca Instantânea: Digite qualquer termo na barra de pesquisa (título, autor, ano ou palavra-chave) para encontrar o documento em milissegundos.
  • Inspetor de Documentos: Clique em qualquer documento para ver a capa, a ficha catalográfica e a citação pronta na ABNT NBR 6023.
  • Copiar Citação com 1 Clique: Clique no botão Copiar Citação e cole diretamente no seu arquivo do Word, Google Docs ou editor LaTeX. O título virá destacado em negrito normativo sem erros de edição.
  • Abrir PDF e Revelar no Finder: Clique nos botões dedicados do inspetor para abrir o arquivo no leitor padrão do macOS ou para ver a pasta exata no Finder.

6. O que Fazer com Itens em "Revisão Manual"?

Se algum documento aparecer marcado com o selo amarelo de Revisão Manual, não se preocupe: isso acontece apenas se o PDF for uma cópia física muito antiga e ilegível, se o arquivo tiver senha de proteção ou se as cotas de inteligência artificial tiverem atingido o limite temporário.

Basta clicar no filtro Revisão Manual na barra lateral, clicar no documento, conferir o título no painel de aprovação e clicar em Aprovar para concluir a organização.

7. Glossário de Termos Técnicos

ABNT NBR 6023
Norma técnica oficial brasileira que dita como referências bibliográficas devem ser formatadas em trabalhos acadêmicos e científicos.
API Key (Chave de API)
Código de acesso pessoal que funciona como uma credencial segura para conectar seu aplicativo diretamente a um serviço na nuvem (como Gemini ou Claude).
Apple Vision OCR
Tecnologia avançada nativa do Mac que reconhece caracteres e lê textos dentro de fotos e páginas escaneadas usando o próprio processador do computador.
BYOK (Bring Your Own Key)
Filosofia de privacidade em que você utiliza suas próprias chaves de serviço, garantindo que nenhum servidor intermediário tenha acesso aos seus dados.
CAPES/CNPq
Órgãos federais brasileiros de ciência e pós-graduação responsáveis pela tabela oficial que organiza os campos do saber em Grandes Áreas, Áreas Básicas e Subáreas.
DOI (Digital Object Identifier)
Identificador digital único e permanente atribuído a artigos científicos no mundo inteiro (ex: 10.1016/...).
Dry-Run (Modo Simulado)
Execução de teste em que o Tomus simula a organização completa na tela, mas sem copiar ou alterar nenhum arquivo no seu disco rígido.
Fallback (Plano de Reserva)
Mecanismo automático de contingência: se o provedor principal atingir a cota de uso, o Tomus aciona imediatamente o provedor reserva sem parar a operação.
ISBN
Número internacional padronizado de 10 ou 13 dígitos que identifica livros globalmente.
SHA-256 (Hash Criptográfico)
Uma impressão digital numérica calculada a partir do arquivo. Serve para o Tomus detectar arquivos repetidos (duplicatas) com 100% de certeza.
Tomus

Bancada de catalogação científica e organizador acadêmico de PDFs para macOS.
